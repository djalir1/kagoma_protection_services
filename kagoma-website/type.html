How Kagoma sets type

One typeface, used at a few fixed sizes. A security company is read in a hurry — at a gate, on a phone, by an employer with a certificate in hand. Type that draws attention to itself gets in the way of that.

The typeface

Bricolage Grotesque. One variable file carries every weight from 200 to 800 and a condensed width, so the whole site loads 199 KB once and uses it everywhere. It is licensed under the SIL Open Font License: free to use commercially, on the site, on certificates, on printed documents and on signage.

Condensed, and when

The condensed width exists for one job: a long title that must hold one line — a certificate, a poster, a badge. It is never used for reading text, and never mixed with the normal width in the same block.

FIRST AID FOR SECURITY PROFESSIONALS

On a certificate

The name is the largest thing on the sheet, because it is what the document is about. Everything else steps down from it. The number is set in tabular figures so the digits line up when an employer reads it aloud.

KAGOMA
PROTECTION SERVICES
KIRENGA Eric
has successfully completed the programme of study in
LOSS PREVENTION MANAGEMENT

KAGOMA-CERT-2026-000006

Rules

Family name in capitals, given name in ordinary case. KIRENGA Eric. MUKAMANA Jeanne d'Arc. It is how a name is written in Rwanda, and the certificate formats it whatever the office typed.

Tabular figures for anything that is a number. Certificate numbers, phone numbers, amounts, times. font-variant-numeric: tabular-nums so that digits line up in a column.

Body text never below 13px, and never below 16px in a field. A field under 16px makes a phone zoom the page the moment it is tapped.

Do not add a second typeface. Bricolage covers display, heading, body and label. A second face is a decision somebody will have to defend later, and it doubles what every page loads.

Do not set long text in capitals. Capitals are for labels of two or three words. A sentence in capitals is read more slowly, which is the opposite of what a gate needs.

Do not stretch or condense by hand. The condensed width is a real design drawn by the type designer. transform: scaleX() is not, and it shows.
